# Publisher

The Publisher is a future application for preparing and publishing authorized
content to Instagram, TikTok, Facebook, and YouTube.

## Planned responsibilities

- Select an approved file from the Library.
- Choose a destination platform and account.
- Edit captions, hashtags, and scheduling information.
- Publish through each platform's supported authenticated API.
- Track queued, published, and failed attempts.

Publishing and monetization require appropriate rights to the video, audio,
description, and branding. This application will remain separate from downloading
so collected media is never published automatically.
