# Library

The Library application will provide a localhost interface for browsing and
maintaining downloaded media. It is planned after the Downloader MVP.

## Planned responsibilities

- Browse by category, source account, and download date.
- Preview videos with audio and display the original caption.
- Change categories without moving records incorrectly.
- Show all source posts associated with one canonical video.
- Review possible perceptual duplicates.
- Select files for a future publishing queue.
- Export or back up metadata.

The Library will use the same external-drive database and storage packages as the
Downloader. It will not publish content directly.
